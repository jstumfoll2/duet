# Duet website

The static showcase site published at https://jstumfoll2.github.io/duet/ by
`.github/workflows/pages.yml` on every push to `main` that touches `site/`.

Plain HTML and CSS, no build step. Keep it free of trackers, analytics, cookies and external
fonts or scripts. `icon.svg` is the braid launcher icon. When Duet is on F-Droid, fill in the
badge slot marked in `index.html` (hero) and replace the "F-Droid: coming later" chip in Install.

Preview locally: open `site/index.html` in a browser.
